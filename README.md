
# دادوند | Dadvand Legal Study

سامانه فارسی بایگانی، جست‌وجو و مطالعه منابع حقوقی.

## اهداف پروژه

- استخراج متن از PDF، Word و تصاویر
- دریافت متن صفحات اینترنتی
- نگهداری متن استخراج‌شده در پایگاه داده محلی
- جست‌وجو در اسناد و موضوعات حقوقی
- نمایش منبع و متن اصلی مطالب بازیابی‌شده
- رابط کاربری فارسی با حالت روشن و تیره
- تفکیک منابع حقوقی بر اساس دسته‌بندی

## اصل اساسی اعتبار حقوقی

مطالب حقوقی باید بر اساس منابع ثبت‌شده در بایگانی بررسی شوند.

اگر مطلب موردنظر در منابع موجود پیدا نشود، برنامه باید اعلام کند:

«در بایگانی یافت نشد.»

برنامه نباید متن قانونی، شماره ماده، رأی، نظریه مشورتی یا استناد حقوقی را بدون منبع معتبر به‌عنوان واقعیت ارائه کند.

## فناوری‌ها

- Python
- Streamlit
- SQLite
- PyPDF
- pdfplumber
- python-docx
- Pillow
- Tesseract OCR
- Requests
- BeautifulSoup

## اجرای محلی

ابتدا وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

سپس برنامه را اجرا کنید:

```bash
streamlit run app.py
```

## وضعیت پروژه

این پروژه در مرحله توسعه اولیه است. پیش از استفاده واقعی، باید استخراج متن، OCR، ذخیره‌سازی، جست‌وجو، حفظ منابع و امنیت اطلاعات آزمون شوند.

## حفظ حریم خصوصی

اسناد حقوقی ممکن است حاوی اطلاعات محرمانه باشند. پیش از بارگذاری اسناد در سرویس‌های میزبانی یا انتشار عمومی، محل ذخیره‌سازی و سطح دسترسی را بررسی کنید.
