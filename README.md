
# دادوند | سامانه مطالعه و بایگانی منابع حقوقی

دادوند یک سامانه برای ثبت، استخراج، بایگانی و جست‌وجوی منابع حقوقی است.

## قابلیت‌ها

- ثبت و بایگانی اسناد حقوقی
- استخراج متن از فایل‌های PDF
- OCR برای PDFهای اسکن‌شده و تصاویر
- استخراج متن از فایل‌های Word
- دریافت متن صفحات اینترنتی از طریق URL
- جست‌وجو در اسناد و موضوعات ثبت‌شده
- نمایش متن مستند همراه با اطلاعات منبع

## نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

موتور Tesseract و داده زبان فارسی نیز برای OCR لازم است.

## اجرای برنامه

```bash
streamlit run app.py
```

## اصل اعتبار حقوقی

- متن رسمی قوانین، آرای قضایی و نظریات باید عیناً از منابع ثبت‌شده استخراج شود.
- مطالب فاقد منبع معتبر نباید به‌عنوان محتوای حقوقی مستند نمایش داده شوند.
- اگر مطلب موردنظر در بایگانی یافت نشود، سامانه باید این موضوع را صریحاً اعلام کند.
- متن اصلی منبع باید از توضیحات و تحلیل‌های احتمالی جدا باشد.
